# Smart Data Cleaner | پاک‌ساز هوشمند داده

[English](README.md) | **فارسی**

ابزاری مبتنی بر Python و کتابخانه Pandas برای پاک‌سازی خودکار فایل‌های CSV و Excel.

این پروژه عملیات متداول آماده‌سازی داده را خودکار می‌کند؛ از جمله مدیریت مقادیر گمشده، حذف ردیف‌های تکراری، اصلاح فاصله‌های اضافی و تولید گزارش آماری در قالب JSON.

## قابلیت‌ها

- **پشتیبانی از CSV و Excel:** خواندن و ذخیره فایل‌های `.csv` و `.xlsx`
- **مدیریت مقادیر گمشده:** حفظ، حذف یا جایگزینی مقادیر خالی
- **روش‌های جایگزینی:** میانگین (Mean)، میانه (Median) و نما (Mode)
- **جایگزینی اختصاصی ستون‌ها:** امکان انتخاب روش متفاوت برای هر ستون
- **حذف داده‌های تکراری:** حذف اختیاری ردیف‌های تکراری
- **اصلاح فاصله‌ها:** حذف فاصله‌های اضافی ابتدا و انتهای مقادیر متنی
- **حذف ردیف و ستون کاملاً خالی**
- **گزارش JSON:** ثبت آمار عملیات پاک‌سازی
- **رابط خط فرمان (CLI):** اجرای عملیات مستقیماً از ترمینال

## نصب و راه‌اندازی

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/Ventheol/smart-data-cleaner.git
cd smart-data-cleaner
```

یک محیط مجازی بسازید:

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

نصب پروژه و وابستگی‌های اصلی:

```bash
python -m pip install -e .
```

برای نصب ابزارهای توسعه و تست نیز از دستور زیر استفاده کنید:

```bash

```

## نحوه استفاده

پس از نصب، می‌توانید ابزار را مستقیماً از طریق دستور `smart-data-cleaner` اجرا کنید.

ساختار کلی دستور:

```bash
smart-data-cleaner input.csv output.csv
```

برای فایل‌های Excel نیز از همین دستور استفاده کنید:

```bash
smart-data-cleaner input.xlsx output.xlsx
```

### مدیریت مقادیر گمشده

سه استراتژی برای مدیریت مقادیر گمشده وجود دارد.

**۱. حفظ مقادیر گمشده (Preserve)**

به‌صورت پیش‌فرض، مقادیر گمشده در ردیف‌ها و ستون‌های دارای داده حفظ می‌شوند.

```bash
smart-data-cleaner input.csv output.csv
```

**۲. حذف ردیف‌های دارای مقدار گمشده (Drop)**

```bash
smart-data-cleaner input.csv output.csv --missing-strategy drop
```

**۳. جایگزینی مقادیر گمشده (Fill)**

استفاده از یک روش برای تمام ستون‌های قابل پردازش:

```bash
smart-data-cleaner input.csv output.csv --missing-strategy fill --fill-method mode
```

انتخاب روش متفاوت برای ستون‌های مشخص:

```bash
smart-data-cleaner input.csv output.csv --missing-strategy fill --fill-column Age=median --fill-column Embarked=mode
```

روش‌های قابل استفاده:

| روش | توضیح |
|---|---|
| `mean` | جایگزینی با میانگین |
| `median` | جایگزینی با میانه |
| `mode` | جایگزینی با پرتکرارترین مقدار |

توجه: روش‌های میانگین و میانه فقط برای ستون‌های عددی قابل استفاده هستند.

### حذف داده‌های تکراری

برای حذف ردیف‌های تکراری از گزینه زیر استفاده کنید:

```bash
smart-data-cleaner input.csv output.csv --drop-duplicates
```

امکان ترکیب گزینه‌ها نیز وجود دارد:

```bash
smart-data-cleaner input.csv output.csv --missing-strategy drop --drop-duplicates
```

## گزارش عملیات پاک‌سازی

پس از هر عملیات موفق، یک فایل گزارش JSON در کنار فایل خروجی ایجاد می‌شود.

ساختار نمونه:

```text
output/
├── cleaned_data.csv
└── cleaned_data_report.json
```

اطلاعات گزارش شامل موارد زیر است:

- تعداد ردیف‌ها و ستون‌های اولیه و نهایی
- تعداد ردیف‌ها و ستون‌های کاملاً خالی حذف‌شده
- تعداد ردیف‌های تکراری حذف‌شده
- تعداد سلول‌های دارای فاصله اضافی اصلاح‌شده
- تعداد مقادیر گمشده اولیه
- تعداد مقادیر جایگزین‌شده
- تعداد مقادیر گمشده باقی‌مانده
- روش‌های جایگزینی اعمال‌شده

## نمونه عملی: مجموعه‌داده Titanic

پروژه شامل نمونه‌ای از مجموعه‌داده Titanic است.

در مثال زیر، مقادیر گمشده ستون `Age` با میانه و مقادیر گمشده ستون `Embarked` با نما جایگزین می‌شوند:

```bash
smart-data-cleaner examples/raw/titanic/train.csv examples/cleaned/titanic/train_cleaned.csv --missing-strategy fill --fill-column Age=median --fill-column Embarked=mode
```

نتایج ثبت‌شده:

| معیار | نتیجه |
|---|---:|
| تعداد ردیف اولیه | 891 |
| تعداد ردیف نهایی | 891 |
| مقادیر جایگزین‌شده | 179 |
| مقادیر گمشده باقی‌مانده | 687 |
| ردیف‌های تکراری حذف‌شده | 0 |

مقادیر گمشده باقی‌مانده عمدتاً مربوط به ستون `Cabin` هستند که عمداً بدون تغییر باقی مانده است.

برای اجرای تست‌های پروژه:

```bash
python -m pytest -v
```

برای مشاهده میزان پوشش تست‌ها:

## محدودیت‌ها

- در حال حاضر فقط فرمت‌های CSV و XLSX پشتیبانی می‌شوند.
- روش‌های Mean و Median فقط برای ستون‌های عددی مناسب هستند.
- جایگزینی مقادیر یک ستون کاملاً خالی امکان‌پذیر نیست؛ زیرا مقدار آماری مناسبی برای محاسبه وجود ندارد.
- این ابزار برای پاک‌سازی عمومی داده‌های جدولی طراحی شده و اصلاحات تخصصی وابسته به دامنه داده را به‌صورت خودکار تشخیص نمی‌دهد.
